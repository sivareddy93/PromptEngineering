Laboratory Experiments: Closed-Ended Prompts and Open-Ended Prompts

Experiment 2(a) : Closed-Ended Prompts

Experiment Title: Design and Evaluate Closed-Ended Prompts for AI-Based Question Answering Systems

Aim: To create and evaluate Closed-Ended prompts that produce specific and accurate responses from a Large Language Model (LLM).

Objectives:

After completing this experiment, students will be able to:

* Understand the concept of Closed-Ended prompts.
* Design prompts that generate specific answers.
* Analyze the accuracy of AI-generated responses.
* Apply Closed-Ended prompts in question-answering applications.

Software Requirements:

* ChatGPT / Gemini / Claude / Microsoft Copilot
* Internet Connection
* Web Browser

Description: A Closed-Ended Prompt is a prompt that asks for a specific, factual, or limited response. The expected answer is usually a single word, a number, "Yes/No," or a short sentence. These prompts reduce ambiguity and are commonly used in AI-powered search engines, chatbots, examination systems, and virtual assistants.

Algorithm:

1. Open an AI language model.
2. Create a factual question.
3. Submit the prompt.
4. Record the AI response.
5. Verify the correctness of the response.
6. Modify the prompt if necessary.
7. Compare responses from different prompts.
8. Document the observations.

Experimental Procedure

Step 1: Open ChatGPT.

Step 2: Enter the following prompt:

```
What is the capital of Telangana?
```

Step 3: Record the response.

Step 4: Try another prompt.

```
What is the full form of CPU?
```
Step 5: Continue with multiple prompts and record the responses.

Experiment 2(b): Open-Ended Prompts

Experiment Title: Design and Evaluate Open-Ended Prompts for Creative Content Generation Using Large Language Models

Aim: To design Open-Ended prompts that generate creative, descriptive, and detailed responses using AI.

Objectives:

After completing this experiment, students will be able to:

* Understand Open-Ended prompts.
* Create prompts for detailed responses.
* Analyze creativity and quality of AI-generated content.
* Compare different prompt designs.

Software Requirements:

* ChatGPT / Gemini / Claude / Microsoft Copilot
* Internet Connection
* Browser

Description: An Open-Ended Prompt encourages the AI to generate detailed explanations, creative ideas, stories, reports, summaries, or code. There may be multiple valid responses. These prompts are widely used in content generation, education, programming assistance, brainstorming, and creative writing.

Algorithm

1. Open ChatGPT.
2. Write an Open-Ended prompt.
3. Submit the prompt.
4. Read the generated response.
5. Modify the prompt by adding more context.
6. Compare both outputs.
7. Record observations.
8. Evaluate creativity and completeness.

Experimental Procedure

Step 1: Enter the following prompt.

```
Explain Artificial Intelligence with a real-life example.
```

Step 2: Observe the response.

Step 3:Modify the prompt.

```
Explain Artificial Intelligence to first-year engineering students using simple language and real-life examples.
```

Step 4: Compare the responses.
